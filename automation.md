# Weekly Safety-Tip Automation

## Safe minimum viable automation
This repository includes `automation/weekly-tip-template.md`. Use it as the message template for a weekly draft. A human must review each tip and its official source before sending.

## Manual workflow
1. Choose one theme for the week (PIN, OTP, QR codes, KYC links, fake support, urgency).
2. Ask an AI tool to draft one short WhatsApp-ready tip using Prompt 8 in `prompt-library.md`.
3. Verify every factual claim against RBI, NPCI, CERT-In or the official cybercrime portal.
4. Check Tamil with a fluent speaker if translating.
5. Remove unverified phone numbers and links; retain only official links.
6. Copy the reviewed message into WhatsApp yourself. Do not automatically message people without their consent.

## Optional no-code automation
Use Make or Zapier only if a suitable free plan is available:
- Trigger: a weekly schedule.
- Action: create a draft from a fixed, safety-reviewed prompt in a document or email draft.
- Human review: verify source and language before distribution.
- Do not connect contact lists, banking accounts or personal data.
- Do not auto-send to a WhatsApp group unless recipients have consented and the setup complies with the platform's terms.

## Example schedule
Every Monday at 9:00 AM, generate a draft only. This example is a plan, not an already-running automation.
